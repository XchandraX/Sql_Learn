# Basis data relasional (RDBMS)
Memang menajadi standa rindustri karena kemampuannya menjaga integritas dan konsistensi data melalui struktur tabel yang saling terhubung

Beberapa komponen penting yang melengkapi struktur ini meliputi:

- Primary Key (Kunci Utama): Tanda pengenai unik untuk setiap baris atau record dalam sebuah tabel (misalnya: `ID_Pelanggan`)

-Foreign Keyu (Kunci Asing): Kolom yang merujuk pada Primary Key di tabel lain untuk mengunci relasi antar entitas (misalnya, menempatkan `ID_Pelanggan` di tabel `Pesanan`).

- SQL (Structured Query Language): Bahasa baku yang digunakan untuk berinteraksi dengan database - seperti membaca, menambah, memperbarui, dan menghapus data.

Contoh sistem populer yang menggunakan model relasional ini termasuk MySQL, PostgreSQL, Oracle, dan Microsoft SQL Server.
